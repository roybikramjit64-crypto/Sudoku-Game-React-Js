# Sudoku Game - React + Vite

A clean, interactive Sudoku game built with React.

### What I Learned

-Creating and using Components
-Import / Export files
-Using `useState` and `useEffect` for state management
-Passing data with Props
-Handling user input and validation in React

### Features

-9x9 interactive board
-Input validation (row, column, 3x3 box)
-Check solution
-Responsive design

### Tech Stack
-React
-Vite
-JavaScript
